# アフィリエイト収益化リサーチ (2026-04-13)

実際に成果を出している個人クリエイター/アフィリエイターの公開情報を5ソース横断で抽出。
出典は文末参照リンク集。**自社の記事生成プロンプト・戦略立案に組み込むことを目的とした内部ノート。**

---

## TL;DR — 個人ブロガー/note向け、月1万→月10万円の現実的なロードマップ

1. **特化** > 雑記。1ジャンルに50記事貯めるまではジャンルを変えない。
2. **競合の弱いキーワード**を選ぶ。検索1ページ目に企業メディアが並んでいるキーワードは個人では勝てない。
3. **高単価案件 (1件¥1,000以上)** を主力にする。低単価Amazonは累積戦、高単価は1件で月¥1,000閾値を超える。
4. **セールスライティング**で CVR を1% → 3% に上げると、報酬は文字通り3倍になる。
5. **継続性 > 完璧主義**。デザイン・SEO技術論に時間を使うのは罠。執筆時間に全振り。
6. **note特有**: 公式ハッシュタグ + AI系トレンドタグで運営おすすめ枠を狙う。3〜5タグが最適。

## ソース別の知見

### 1. クラシキログ (note月¥175,000、2025-12 実績)

**プロフィール**: ガジェット・生活情報系の特化メディア。月20万PV。

**実績の内訳**:
- Amazon: ¥146,755
- 楽天: ¥16,794
- その他: ¥12,085
- **合計**: ¥175,634 (月7記事更新)

**戦術**:
- ガジェット・家電系1ジャンルに完全特化
- 有料note は出さず、アフィリエイト中心の単一戦略
- 自然な流れで Amazon リンクを記事内に埋め込む (商品レビュー型)
- 月10記事前後の安定更新
- noteプラットフォーム内の認知 + 検索流入 + SNS流入の3本柱

**自社への示唆**:
- Bluesky 起点の記事も「ガジェット/家電」軸で書ければAmazon親和性が高い
- 「実際に使ったレビュー」感が出ないとCVRが落ちる → ハルシネーション抑止と矛盾しない
  範囲で「公式仕様 + 一般的なユースケース」で書く

### 2. いちのせSEO (放置型サイトで月500万円, IQ152の異常値)

**プロフィール**: 一橋→商社→アフィリ独立。サイト売却益も含む不労所得型。

**やめてよかった失敗パターン**:
- 「**かっこいいサイトデザイン**」に時間を使う → 売却時の評価には収益額しか効かない
- 「**細かいSEO技術論**」に時間を使う → センターピンは記事内容、それ以外は誤差
- 「**雑記サイト**」を続ける → Googleがサイト権威を認識しにくい
- 「**RSS送信ツール30個**」「**サイト更新通知**」みたいなマイクロ施策 → 全部誤差
- 「**競合の強いキーワード**」を狙う → 個人が企業メディアと殴り合っても順位は維持できない
- リライトでループに入って新規記事が書けなくなる

**結局うまくいったこと**:
- **特化サイト化** (Googleがサイト権威を認識する)
- **競合が弱いキーワード**だけを狙う
- **記事執筆に時間を全振り** (議論や勉強より執筆)
- **完成したら基本放置**できる構造を最初から設計

**自社への示唆**:
- AIで大量生成 = 雑記サイトと同じ弱点。**ジャンルを絞った特化チャンネル化**が必要
- 競合キーワード分析を generate 前に挟む価値あり
- 既存記事のリライトループに陥らない (新規記事優先)

### 3. まい (3年苦戦 → noteで月1万円達成)

**プロフィール**: 副業迷子。アフィリで3年やって月数百円から抜け出せず、有料noteで突破。

**学び**:
- 「アフィリエイト一本」で何年やっても収益が安定しないパターンは多い
- 同じ労力なら**有料note (¥300〜¥500の小コンテンツ)** のほうが収益化難易度は低い
- 月¥1万円達成は「アフィリ + 有料note + サポート」のハイブリッド構成

**自社への示唆**:
- アフィリエイトだけに依存せず、**有料note** や **メンバーシップ** も併用余地あり
- ただし有料note を出すには「読者がお金を払いたくなる固有のノウハウ」が必須

---

### 4. ちしきや (現役副業ブロガー、A8.net 攻略)

**プロフィール**: ITベンチャーWebマーケター。2022年8月にブログ開始。

**A8.net で稼げない人の共通失敗**:
1. **単価の安い案件**ばかり扱う → 1件¥1,000以上のものを中心に
2. **高単価案件**を「怖い」と感じて避ける → 高単価でも機能性が高ければ読者は喜ぶ
3. **SEO 学習をサボる** → 「陸上幅跳びの選手がジャンプ練習しないレベルで意味不明」
4. **「自分のブログから誰も買わない」**という固定観念 → 実際は普通に売れる (本人実例: 月10件の購入/登録)
5. **セールスライティングを学ばない** → CVR 1% を 3% に上げれば収益3倍

**実際の数字**:
- 主力案件: 1件¥10,000 (高単価)
- 月の成約: 10件程度
- ASP併用: A8.net + afb + もしも + その他 計6社 (案件被りカバー)

**自社への示唆**:
- 通信案件 (auひかり ¥10,000〜¥30,000) は1件成約で振込閾値を即超え
- セールスライティングのテクを Gemma3 プロンプトに組み込む (下記参照)

### 5. みひろ (note ハッシュタグ ランキング分析)

**プロフィール**: noteのタグ動向をデータ分析。

**2025年のタグ動向**:
- **AI系タグが激増**: #ChatGPT, #Gemini, #生成AI が1.5ヶ月で記事数大幅増
- **季節公式タグ**: 「秋のお気に入り」「秋だからやってみた」等の note運営が用意した時宜タグ
- **公式タグ**: note運営チームの目に留まりやすい → おすすめ枠掲載のチャンス
- **タグ数の最適**: 3〜5個 (汎用 + 特化のミックス)

**自社への示唆**:
- 既に `HashtagGenerator` を持っているが、**公式タグ** の検出/優先付けロジック追加余地
- **AI ジャンル記事** (Claude, Gemini, ChatGPT 系) は note内でも追い風

## セールスライティング — CVRを上げる即効テクニック

ちしきや記事 + 業界一般知識から:

1. **ベネフィットを先に書く** (「機能」ではなく「読者の生活がどう変わるか」)
2. **数字を入れる** (「3分でできる」「90%が知らない」「月¥1,000節約」)
3. **読者の Before / After を描写**
4. **不安を先に潰す** (「初心者でも」「無料で試せる」「解約ペナルティなし」)
5. **CTAは記事末だけでなく中盤にも置く** (中盤離脱者のキャッチ)
6. **比較表 or 順位** (読者が選ぶ手間を省く)

## 運用パターン4類型 (実例ベース)

リサーチを通じて見えてきた個人アフィリエイターの運用パターンは大まかに4つ。
**自社の AI auto publisher は今のところ C と D の混合形だが、戦略を意識しないと
A 型の幻想に引きずられる**。

### 🅐 ガッツ型 (Manual Push)

**典型像**: 副業会社員、独力でゼロから月10万円を目指す。

| 項目 | 内容 |
|---|---|
| 時間投入 | 平日 1〜4時間/夜 + 週末まとめ作業 |
| 1記事所要 | 4〜6時間 (構成・執筆・画像・公開込み) |
| ペース | 月10〜30記事 |
| 達成期間 | 月1万円まで6ヶ月、月10万円まで12〜18ヶ月 |
| ツール | WordPress + ラッコキーワード + Canva + ASP管理画面 |
| 強み | 文章に独自体験・感情・写真が乗る (CVR高い) |
| 弱み | スケールしない / 続かない人多数 / 燃え尽きやすい |

### 🅑 ハイブリッド型 (AI Draft × Human Edit)

**典型像**: ChatGPT/Claude で下書き → 人間が体験談・固有情報を上書き。月20-30万円達成例あり。

| 項目 | 内容 |
|---|---|
| 時間投入 | 1記事 1〜2時間 (執筆短縮、編集に集中) |
| AI担当 | タイトル案、見出し、本文ドラフト、装飾 |
| 人間担当 | キーワード選定、構成判断、体験談注入、リライト戦略 |
| ペース | 月20〜50記事 |
| 達成期間 | 月10万円まで 6〜12ヶ月 (継続性勝負) |
| ツール | ChatGPT (Plus) or Claude + ラッコキーワード + WordPress + ASP |
| 成功の鍵 | **「AI任せにしない」**。共感・固有体験・出典が品質を分ける |
| 失敗例 | 自動生成そのまま投下 → アクセス伸びず → リライトの繰り返しで継続不能 |

### 🅒 完全自動型 (Full Automation)

**典型像**: WordPress自動連携ツール + LLM で量産。プロンプト設計に集中。

| 項目 | 内容 |
|---|---|
| 時間投入 | 初期設計に集中、運用は週数時間 |
| ペース | 月100記事+ も可能 |
| 達成例 | 月30万円 (ただし「8ヶ月の継続」必要) |
| 強み | スケール、夜寝てる間にも生成 |
| 弱み | LLMOがしっかりしないとGoogleに低品質判定される / Amazon審査で蹴られる |
| 重要施策 | LLMO最適化 (構造化データ / FAQスキーマ / 固有名詞正確化) |

→ **自社の auto publisher はここに分類**。ただし「特化サイトでない雑記化」している
  のが伸び悩みの原因と推定される。

### 🅓 特化×低頻度型 (Niche × Quality)

**典型像**: 1ジャンル特化、月10記事だけ書く。クラシキログ氏 (月¥175k 実績)。

| 項目 | 内容 |
|---|---|
| 時間投入 | 月20〜40時間 |
| ペース | **月7〜10記事のみ** |
| ジャンル | 1つに完全特化 (ガジェット/家電/旅行/etc) |
| PVソース | 検索 + SNS + プラットフォーム内 |
| 月収例 | ¥175,634 (Amazon中心、月20万PV) |
| 強み | 少ない労力で高収益、AI支援なしでも回る |
| 弱み | ジャンル選定ミスで全部無駄になる |

→ **記事数を絞ってでも特化する** という、自社の AI 量産戦略とは真逆の発想。

## 各パターン共通の必須ツールスタック

| カテゴリ | 無料 | 有料 |
|---|---|---|
| キーワード調査 | ラッコキーワード, Googleキーワードプランナー | Ahrefs (¥約12,000/月), GRC, ubersuggest |
| 執筆支援 | ChatGPT Free, Gemini, Claude.ai | ChatGPT Plus (¥3,000/月), Claude Pro |
| 画像 | Canva Free, Unsplash, Pexels | Canva Pro, Midjourney |
| ブログ基盤 | WordPress.com, note | WordPress.org + サーバー |
| 解析 | Google Analytics, Search Console | Ahrefs Lite |
| ASP | A8.net, もしも, afb, バリューコマース, アクセストレード (全部無料登録) | (なし) |

→ **無料スタックでも月10万円は到達可能**。有料に投資するのは月3万円超えてから。

## 1日の運用例 (副業会社員の典型)

```
06:30  起床
07:00  通勤中: スマホで X/note のトレンド観察、ネタ探し (15分)
12:00  ランチ中: ラッコキーワード で午前中浮かんだネタの検索ボリューム調べ (10分)
21:00  帰宅・夕食後にPC前へ
21:00-23:00  記事執筆 / リライト (2時間集中)
23:00-23:30  ASP管理画面 + Search Console チェック → 翌日のネタ書き出し
```

**続かない人の典型**: 完璧を求めて1記事に1週間、3記事書いて燃え尽き。
**続く人の特徴**: 「1日30分でも触る」「公開ボタン押すまでが仕事」「リライトは後回し」

## 自社 AI Auto Publisher の現在地と次の一手

**現在地**: 完全自動型 🅒 だが、ジャンルが雑 (AI論文 / グルメ / コーヒー / 韓国 / マネタイズ等)。
これは🅒の**典型的な失敗パターン** = 雑記化により Google サイト評価が積み上がらない。

**次の一手 (ナレッジに基づく優先順位)**:
1. **🅓化のシミュレート** — note を「**月のメインジャンル**」固定運用にして、
   その月だけは1ジャンルしか generate しない。月毎にローテすれば多ジャンル網羅可。
2. **🅑モード追加** — 重要度が高い記事 (高単価CTA含む) は人間レビューを挟むフラグ
   を立て、Slack で承認→公開フローに乗せる。
3. **LLMO最適化** — 構造化データ、FAQ、固有名詞の正確化 (Codex/Places API研究済)
4. **計測** — A8/Amazonの管理画面API or RSS 連携で「どの記事が稼いだか」を
   feedback ループに組み込む
