# アフィリエイト収益化リサーチ (2026-04-13)

実際に成果を出している個人クリエイター/アフィリエイターの公開情報を5ソース横断で抽出。
出典は文末参照リンク集。**自社の記事生成プロンプト・戦略立案に組み込むことを目的とした内部ノート。**

---

## TL;DR — 個人ブロガー/note向け、月1万→月10万円の現実的なロードマップ

1. **特化** > 雑記。1ジャンルに50記事貯めるまではジャンルを変えない。
2. **競合の弱いキーワード**を選ぶ。検索1ページ目に企業メディアが並んでいるキーワードは個人では勝てない。
3. **高単価案件 (1件¥1,000以上)** を主力にする。低単価Amazonは累積戦、高単価は1件で月¥1,000閾値を超える。
4. **セールスライティング**で CVR を1% → 3% に上げると、報酬は文字通り3倍になる。
5. **継続性 > 完璧主義**。デザイン・SEO技術論に時間を使うのは罠。執筆時間に全振り。
6. **note特有**: 公式ハッシュタグ + AI系トレンドタグで運営おすすめ枠を狙う。3〜5タグが最適。

## ソース別の知見

### 1. クラシキログ (note月¥175,000、2025-12 実績)

**プロフィール**: ガジェット・生活情報系の特化メディア。月20万PV。

**実績の内訳**:
- Amazon: ¥146,755
- 楽天: ¥16,794
- その他: ¥12,085
- **合計**: ¥175,634 (月7記事更新)

**戦術**:
- ガジェット・家電系1ジャンルに完全特化
- 有料note は出さず、アフィリエイト中心の単一戦略
- 自然な流れで Amazon リンクを記事内に埋め込む (商品レビュー型)
- 月10記事前後の安定更新
- noteプラットフォーム内の認知 + 検索流入 + SNS流入の3本柱

**自社への示唆**:
- Bluesky 起点の記事も「ガジェット/家電」軸で書ければAmazon親和性が高い
- 「実際に使ったレビュー」感が出ないとCVRが落ちる → ハルシネーション抑止と矛盾しない
  範囲で「公式仕様 + 一般的なユースケース」で書く

---

### 2. いちのせSEO (放置型サイトで月500万円, IQ152の異常値)

**プロフィール**: 一橋→商社→アフィリ独立。サイト売却益も含む不労所得型。

**やめてよかった失敗パターン**:
- 「**かっこいいサイトデザイン**」に時間を使う → 売却時の評価には収益額しか効かない
- 「**細かいSEO技術論**」に時間を使う → センターピンは記事内容、それ以外は誤差
- 「**雑記サイト**」を続ける → Googleがサイト権威を認識しにくい
- 「**RSS送信ツール30個**」「**サイト更新通知**」みたいなマイクロ施策 → 全部誤差
- 「**競合の強いキーワード**」を狙う → 個人が企業メディアと殴り合っても順位は維持できない
- リライトでループに入って新規記事が書けなくなる

**結局うまくいったこと**:
- **特化サイト化** (Googleがサイト権威を認識する)
- **競合が弱いキーワード**だけを狙う
- **記事執筆に時間を全振り** (議論や勉強より執筆)
- **完成したら基本放置**できる構造を最初から設計

**自社への示唆**:
- AIで大量生成 = 雑記サイトと同じ弱点。**ジャンルを絞った特化チャンネル化**が必要
- 競合キーワード分析を generate 前に挟む価値あり
- 既存記事のリライトループに陥らない (新規記事優先)

### 3. まい (3年苦戦 → noteで月1万円達成)

**プロフィール**: 副業迷子。アフィリで3年やって月数百円から抜け出せず、有料noteで突破。

**学び**:
- 「アフィリエイト一本」で何年やっても収益が安定しないパターンは多い
- 同じ労力なら**有料note (¥300〜¥500の小コンテンツ)** のほうが収益化難易度は低い
- 月¥1万円達成は「アフィリ + 有料note + サポート」のハイブリッド構成

**自社への示唆**:
- アフィリエイトだけに依存せず、**有料note** や **メンバーシップ** も併用余地あり
- ただし有料note を出すには「読者がお金を払いたくなる固有のノウハウ」が必須

---

### 4. ちしきや (現役副業ブロガー、A8.net 攻略)

**プロフィール**: ITベンチャーWebマーケター。2022年8月にブログ開始。

**A8.net で稼げない人の共通失敗**:
1. **単価の安い案件**ばかり扱う → 1件¥1,000以上のものを中心に
2. **高単価案件**を「怖い」と感じて避ける → 高単価でも機能性が高ければ読者は喜ぶ
3. **SEO 学習をサボる** → 「陸上幅跳びの選手がジャンプ練習しないレベルで意味不明」
4. **「自分のブログから誰も買わない」**という固定観念 → 実際は普通に売れる (本人実例: 月10件の購入/登録)
5. **セールスライティングを学ばない** → CVR 1% を 3% に上げれば収益3倍

**実際の数字**:
- 主力案件: 1件¥10,000 (高単価)
- 月の成約: 10件程度
- ASP併用: A8.net + afb + もしも + その他 計6社 (案件被りカバー)

**自社への示唆**:
- 通信案件 (auひかり ¥10,000〜¥30,000) は1件成約で振込閾値を即超え
- セールスライティングのテクを Gemma3 プロンプトに組み込む (下記参照)

### 5. みひろ (note ハッシュタグ ランキング分析)

**プロフィール**: noteのタグ動向をデータ分析。

**2025年のタグ動向**:
- **AI系タグが激増**: #ChatGPT, #Gemini, #生成AI が1.5ヶ月で記事数大幅増
- **季節公式タグ**: 「秋のお気に入り」「秋だからやってみた」等の note運営が用意した時宜タグ
- **公式タグ**: note運営チームの目に留まりやすい → おすすめ枠掲載のチャンス
- **タグ数の最適**: 3〜5個 (汎用 + 特化のミックス)

**自社への示唆**:
- 既に `HashtagGenerator` を持っているが、**公式タグ** の検出/優先付けロジック追加余地
- **AI ジャンル記事** (Claude, Gemini, ChatGPT 系) は note内でも追い風

## セールスライティング — CVRを上げる即効テクニック

ちしきや記事 + 業界一般知識から:

1. **ベネフィットを先に書く** (「機能」ではなく「読者の生活がどう変わるか」)
2. **数字を入れる** (「3分でできる」「90%が知らない」「月¥1,000節約」)
3. **読者の Before / After を描写**
4. **不安を先に潰す** (「初心者でも」「無料で試せる」「解約ペナルティなし」)
5. **CTAは記事末だけでなく中盤にも置く** (中盤離脱者のキャッチ)
6. **比較表 or 順位** (読者が選ぶ手間を省く)
