# Note学習戦略ドキュメント

## 学習の目的
月60万円自動収益を目標に、note人気記事のパターンを継続的に学習し、生成記事の品質を向上させる。

## 学習サイクル

### 日次（自動）
- 平日 0/5/9/14時に generate実行 → 新規記事を収集・生成
- 生成済みソースは重複防止で記録

### 週次（自動・日曜3時）
- `main.py --learn` で5カテゴリから約85記事取得
- パターン分析して `docs/knowledge/note-trends/` に更新

### 月次（手動推奨）
- cumulative.jsonをリセット
- 新しいカテゴリセットで深掘り学習
- メガレポート生成 → プロンプトへ反映

## 蓄積されたデータ

### ファイル
- `docs/knowledge/note-trends/cumulative.json` — 累積記事DB（2026-04-08時点: 2057件）
- `docs/knowledge/note-trends/2026-04-08_mega_report.md` — メガ分析レポート
- `docs/knowledge/note-trends/paid_analysis.md` — 有料記事分析
- `docs/knowledge/note-trends/top_authors.md` — トップ著者
- `docs/knowledge/note-trends/prompt_suggestions.md` — プロンプト改善提案

### 主要な学習結果 (2026-04-08時点)
- **2057記事** を **125カテゴリ** から収集
- 有料記事12.6% (¥100〜¥59,800, 平均¥1,685)
- 中央値文字数: 2500字前後
- H2見出し: 平均4.8個

## 伸びるパターン

### タイトル
1. 【◯◯】括弧プレフィックスが必須
2. 35〜45文字
3. 数字を含める
4. 「完全」「最新」「徹底」「殿堂入り」などの強い形容詞
5. AI/ChatGPT/Claude/Gemini系の時事ワード

### 構造
1. H2見出し5〜10個
2. 3000〜5000字（超ガイド型は20000字超もOK）
3. 画像は少なめでもOK（文字だけで勝負できる）

### 有料化
- 中央値¥1,685
- 上位は¥3,000〜¥5,000の実用ガイド
- ¥10,000超の記事は少数だが存在
