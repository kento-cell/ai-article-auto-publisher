# note マネタイズ基礎

## 無料 vs 有料の判断基準

| 項目 | 無料で出す | 有料で出す |
|------|-----------|-----------|
| 情報の希少性 | 低 | 高 |
| 実装のハンズオン度 | 低 | 高 |
| 調査に時間がかかった | NO | YES |
| 失敗談含む | NO | YES |
| 筆者固有の経験 | NO | YES |

## 価格帯の目安（note）

- **¥100-300**: 入門・概要・ネタ
- **¥500-980**: 実装手順・ノウハウ
- **¥1,000-1,980**: 完全自動化・高度な技術
- **¥2,000+**: ビジネス戦略・独自リサーチ

## タイトルのパターン

### 売れるタイトル型
- 「〇〇で月△万円達成した全手順」
- 「知らないと損する〇〇」
- 「〇〇で失敗した話と学び」
- 「プロが教えない〇〇の裏側」
- 「【保存版】〇〇の完全ガイド」

### 避けるべき
- 抽象的・学術的なタイトル
- 「やってみた」だけで中身がない
- キーワードが曖昧

## 導入文の3行ルール

1行目: 読者の悩みを共感
2行目: この記事で解決できること
3行目: なぜ筆者が書けるか（信頼性）

## 本文の構成

1. 問題提起（なぜ重要か）
2. 解決策の全体像
3. ステップバイステップ実装
4. 失敗パターンと対処
5. 応用・発展
6. まとめ + 次のアクション

## 画像・視覚要素

- ヘッダー画像は**必須**（クリック率が段違い）
- 500-800字ごとに視覚ブレイク
- スクリーンショット、図表、Before/After

## ハッシュタグ

- 最大5個、関連性の高いものを
- トレンドタグ + ニッチタグの組み合わせ
