# ローカルLLM (Gemma3) 活用のコツ

## Gemma3 12B の特徴

### 強み
- 日本語の文章生成が自然
- コスト0円、プライバシー安全
- RTX 3070 + 32GB RAMで動く

### 弱み
- 指示追従力がClaude/GPTより弱い
- 長文の構造を守りにくい
- 引用ブロックや見出しを省略しがち

## プロンプトのコツ

### 具体例を入れる
抽象的な指示より、**出力フォーマットの例**を与える方が効果的。

```
良い例:
以下のフォーマットで記事を書いてください。
## はじめに
（導入文）
## 本題1: XXX
（内容）
> "引用文"
> 出典: https://example.com
```

### チェックリスト形式
「〜を含めてください」より「必ず以下を満たす」形式：

```
必須条件:
□ H2見出しを最低4個
□ 引用ブロックを最低3個
□ コードブロックを最低1個
```

### 温度設定
- **記事生成**: 0.7（創造性重要）
- **批評・評価**: 0.3（厳密性重要）
- **要約**: 0.5（バランス）

## よくある問題と対処

### 指示を無視して短くなる
→ 「最低3000字書いてください」と字数指定

### 英語混じりになる
→ 「日本語のみで書いてください」と明記

### 構造がバラバラ
→ プロンプトの冒頭で「構成」セクションを明示

### 同じ語彙を繰り返す
→ repeat_penalty パラメータを1.1-1.3に

## トークン節約

- プロンプトは長すぎないように
- 必要ないコンテキストは削る
- generate時に context を絞る

## バックアップ戦略

Gemma3が品質基準を満たせない場合：
1. プロンプトの例示を強化
2. max_retries で数回試行
3. 最後はユーザー承認を必須に
