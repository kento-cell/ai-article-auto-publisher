# 要件定義書: AI記事自動生成・投稿システム

## 1. システム概要

### 1.1 目的
外部ソースから情報を自動収集し、AIで高品質な記事を生成、Zenn/noteに半自動で投稿するシステム。
単なる翻訳・要約ではなく、**独自の視点と深い考察を加えた、読む価値のあるコンテンツ**を生産する。

### 1.2 システム名
AI Article Auto Publisher

### 1.3 運用体制
- **半自動運用**: 生成後に人間が確認してから投稿
- 収集・生成は自動、投稿前に承認フローを挟む
- 日次で結果を確認・調整

## 2. 対象プラットフォームとコンテンツ戦略

### 2.1 Zenn（技術記事プラットフォーム）

**ターゲット読者**: 日本のソフトウェアエンジニア（ジュニア〜シニア）

**コンテンツ方針**:
- 国内外問わず技術的なナレッジを収集・発信
- テクニカルな深い解説記事（薄い内容は不可）
- IT業界以外の業界ネタも技術視点で取り上げる
- 実装例・コード・アーキテクチャ図を豊富に含む
- 元記事の翻訳ではなく、日本のエンジニア向けに再構成・価値付加

**収集ソース**:
| ソース | 種別 | 理由 |
|--------|------|------|
| arXiv | 論文 | AI/ML最前線の一次情報 |
| Google Research Blog | ブログ | 大規模システムの実践知見 |
| Anthropic Blog | ブログ | LLM最新動向 |
| OpenAI Blog | ブログ | GPT系最新情報 |
| Hacker News | アグリゲータ | エンジニアコミュニティのトレンド |
| GitHub Trending | リポジトリ | 注目OSSの早期キャッチ |
| IEEE/ACM | 論文 | CS全般の学術トレンド |

**記事品質要件**:
- 文字数: 2,500〜3,500字（コード除く）
- コードブロック: 最低1箇所、実行可能な完全版
- 図表: Mermaid記法で最低1つのアーキテクチャ図/フロー
- 引用: 全データ・主張に出典明記（URL + 取得日）
- 構成: 導入→概要→技術詳細→実践示唆→まとめ→参考文献

### 2.2 note（一般向けプラットフォーム）

**ターゲット読者**:
- ジャンル横断のナレッジ消費層
- 課金してでも読みたい質の高い情報を求める層
- 特定トピックにコアな関心を持つ読者

**コンテンツ方針**:
- ジャンル問わずHOTなニュース・ナレッジ
- **課金してでも読みたいと思わせる深さ・独自性**
- コアな層に刺さるニッチで濃い内容
- 表面的なまとめ記事は不可（薄い内容は絶対NG）
- 引用元の明示と信用度の高いソース選定

**収集ソース**:
| ソース | 種別 | 理由 |
|--------|------|------|
| Reddit | コミュニティ | グローバルトレンドの早期発見 |
| Twitter/X | SNS | リアルタイムの話題性 |
| YouTube | 動画 | バイラルコンテンツ・解説系 |
| TikTok | 動画 | Z世代トレンド |
| Google Trends | 検索 | 検索需要の急上昇 |
| Product Hunt | プロダクト | 新サービス・ツール |
| 各業界専門メディア | ニュース | 信頼性の高い一次情報 |

**記事品質要件**:
- 文字数: 2,500〜3,500字
- 図表: 比較表・Before/After・Mermaidフロー
- 引用: 全ソースにURL + 取得日、信用度の高いソース優先
- トーン: です・ます調、専門用語は平易に解説
- 構成: 導入（なぜ話題か）→本文→実践方法→まとめ→参考リンク

## 5. 有料化戦略（note）

### 5.1 価格設計思想

**品質に比例する価格設定**を採用。記事の品質スコアが高いほど価値があると判断し、それに応じた価格をつける。

### 5.2 価格テーブル

| Tier | 品質スコア範囲 | 価格 | 想定コンテンツ |
|------|---------------|------|---------------|
| Free | 0〜699 | ¥0 | 一般的なトレンド記事、導入的な内容 |
| Tier 1 | 700〜999 | ¥300 | まとまった解説、中程度の深さ |
| Tier 2 | 1,000〜1,499 | ¥500 | 深い分析、独自視点あり |
| Tier 3 | 1,500〜1,999 | ¥980 | 専門的、コアな層向け |
| Tier 4 | 2,000+ | ¥1,980 | 極めて高品質、独自調査・検証付き |

### 5.3 有料化の条件

- 品質スコアが閾値を超えているだけでなく、以下を満たすこと:
  - 引用元がすべて信用度の高いソース
  - 独自の分析・考察が含まれている
  - 他では読めない価値がある
- **薄い内容を有料にすることは絶対にしない**

## 7. 法的・倫理的要件

### 7.1 著作権

| 要件 | 対応 |
|------|------|
| 元記事の無断転載禁止 | 引用は著作権法の引用要件を満たす範囲に限定 |
| 引用の明示 | 全引用にソース名、URL、取得日を明記 |
| オリジナリティ | 単なる翻訳・転載ではなく、独自の価値を付加 |

### 7.2 画像著作権

| 要件 | 対応 |
|------|------|
| 使用可能画像 | CC0、Unsplash License、Pexels License、AI生成、自作図表のみ |
| 帰属表示 | CC0でも撮影者名・プラットフォーム名を記載 |
| ホットリンク���止 | 画像はダウンロードしてリポジトリ/ストレージに配置 |
| alt text必須 | 全画像にアクセシビリティ対応の代替テキスト |
| スクリーンショット | フェアユース範囲（検証記事の証拠としてのみ） |
| 商用利用 | note有料記事での使用に耐えるライセンスであること |

### 7.3 プラットフォーム規約

| 要件 | 対応 |
|------|------|
| Zenn利用規約 | Git連携による正規投稿フロー |
| note利用規約 | AI生成コンテンツのポリシーを確認・遵守 |
| 有料記事の返金 | noteの返金ポリシーに準拠 |

### 7.3 倫理

| 要件 | 対応 |
|------|------|
| AI生成の明示 | 記事末尾にAIアシスト利用を明記（要検討） |
| 誤情報防止 | 品質評価の「正確性」軸で担保 |
| 誇大表現禁止 | 禁止フレーズリストで機械的に排除 |

## 8. 制約事項

| 制約 | 影響 | 対応 |
|------|------|------|
| Claude.ai無料枠のトークン制限 | 大量生成不可 | 週次予算管理 + ローカルLLMフォールバック |
| Selenium依存（note, Claude.ai） | UI変更で破損するリスク | セレクタの外部化、エラー検知→即通知 |
| 会社PC制限 | インストール制約の可能性 | D:\ForWorking内で完結 |
| note APIの非公開 | 公式連携不可 | Selenium経由（規約確認要） |
