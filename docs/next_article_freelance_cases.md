## 推奨アングル

- 成功"後"の華やかさではなく、成功"前"に何を積んだかにフォーカス。
- ランサーズのAI人材2.5倍増（後述）= チャンスだが競合も増えた、という両面を正直に書く。
- 読者の持ち帰り = 「再現できる部分」と「運・経歴依存の部分」を切り分けたロードマップ。

## リサーチ済みファクト（すべて出典付き・捏造なし）

### 市場データ

- AIエンジニアのフリーランス単価: 週5稼働で月60〜90万、150万超の案件も存在、
  実績次第で年収1,000万円以上も可能（Relance / coeteco）。
- AIエンジニア案件の年収水準 約999万円（フリーランスボード調べ, 2025年12月時点 / INSTANTROOM）。
- AIエンジニアの募集中フリーランス案件数 1,426件（2025年7月時点）、累計掲載7,656件
  （フリーランススタート調べ）。
- RAG関連の副業案件: 月80〜100万の高単価あり、週1〜2日稼働で月20万円以上、
  時給換算4,000〜5,000円（テックジム / OPSIZM）。
- ランサーズのAI関連スキル保有フリーランス・副業人材: 2024年 約3,600名 →
  2025年6月 9,000名超（約2.5倍）（ランサーズ プレスリリース）。

### 成功事例（実際に公開された体験談ベース）

- **ケースA（積み上げ型）**: 完全未経験 → 2年1ヶ月で月収112.5万円を達成した公開実体験
  （フロントエンド志望ルート / magicgifted）。
- **ケースB（実務経験活用型）**: 2020年にサーバーサイドエンジニアとして独立 →
  2022年に年間売上1,000万円超（個人ブログの実体験ロードマップ）。
- **ケースC（専門特化×直請け型）**: 大手企業で5年以上のAI開発経験を積み、独立後に
  画像認識・自然言語処理の専門領域でメーカー・金融と直接契約、会社員時代より高報酬
  （フリーランスエージェント媒体が紹介する典型パターン）。
  ※ケースCは個人名付きの事例ではなく「典型パターン」として扱う（誇張しない）。

### 成功の共通項（各ソースで繰り返し挙がる要素）

1. 独立前の実務経験が"信頼の担保"（AI系で3〜5年、一般エンジニアで1〜3年が目安）。
2. 営業・人脈づくりを継続し、案件パイプラインを切らさない。
3. ポートフォリオを更新し続け、市場価値を維持する。
4. 技術力だけでなく、ビジネス感覚とコミュニケーション能力。

## 記事構成（ドラフト outline）

- **導入** — 「成功事例」の正しい読み方。華やかな結果ではなく"その前"を見る。煽らない宣言。
- **第1部 数字で見る、いまのフリーランス市場**
  - 単価レンジ、案件数の伸び、AI人材2.5倍増。
  - チャンスであると同時に競合も増えた、という両面。
- **第2部 成功事例の解剖 — 3つの型**
  - ケースA 積み上げ型 / ケースB 実務経験活用型 / ケースC 専門特化×直請け型。
  - 各ケースの「成功"前"にやったこと」を抽出。
- **第3部 共通パターン＝再現可能なロードマップ**
  - 実務経験の積み方 / ポートフォリオ / 営業・パイプライン / 値付け。
  - 「再現できる部分」と「経歴・運に依存する部分」を切り分ける。
  - RAG技術書との接続（スキルの作り方は技術書、成果の出し方が本記事）。
- **終章** — 「成功事例」を自分の事例にする。チェックリスト。
