# はじめに ― 韓国コスメで失敗する人の8割は「成分を覚えていない」

韓国コスメを買ってみたけど、思ったほど効かなかった経験はないだろうか。

理由はシンプルで、「自分の肌悩みに合う成分」を選んでいないから。逆に言えば、肌悩み別に4〜5つの成分名を覚えるだけで、ブランドや価格に振り回されずに「これは効きそう」「これはまだ早い」と自分で判断できるようになる。

この記事は、韓国コスメ売り場で「裏面の成分表を見ても何も分からない」状態を抜けるための入門ガイド。鎮静・美白・ハリ・毛穴・乾燥の5つの代表的な肌悩みごとに、いま韓国コスメ業界で主流になっている成分と、その成分が入っている代表的なブランドを紹介する。

ブランド・成分は実在のもののみ。数値や効能は公式サイトや学会で確認できる範囲に絞った。薬機法上の効能断定はしないので、最終的な購入判断は各ブランドの公式情報と自分の肌の反応で決めてほしい。

買う場所をまだ決めていない人は、姉妹記事の[韓国コスメを日本で買う4つの場所](https://note.com/note-user/n/n4e037aa7aeed)を先に読むと、この記事で紹介する成分の入った商品にどこでアクセスできるかが分かる。

## 大前提 ― 自分の肌悩みを「1つ」に絞る

成分選びで最初に失敗する人は、肌悩みを欲張る。

「乾燥もあるけどニキビも気になるし、シミも消したいし、ハリも欲しい」と全方位で考えると、結果として効果が分散して、何が効いているか分からなくなる。さらに複数の有効成分を同時に使うと、肌のキャパシティを超えて逆に炎症を起こすことすらある。

最初の3ヶ月は「今いちばん気になる肌悩み」を1つだけ決めて、その悩みに対応する成分を1つだけ加える。これが韓国コスメに限らず、スキンケアの王道ルール。

もし自分の悩みが分からないなら、3日間鏡を見て一番気になるポイントを言語化する。「赤み」「くすみ」「毛穴」「乾燥」「ハリ不足」のどれかに必ず収まる。

## 鎮静 ― シカ(Centella Asiatica) と マデカソサイド

「赤み」「肌荒れ」「敏感肌」の悩みに対応するのが鎮静系の成分。

韓国コスメで鎮静の代名詞になっているのが Centella Asiatica(センテラ アジアティカ)、通称「シカ」。和名はツボクサで、東南アジア・インド・アフリカに自生する植物。創傷治癒に使われてきた歴史があり、皮膚への鎮静作用は化粧品原料として認められている。

製品の成分表では「Centella Asiatica Extract」「Centella Asiatica Leaf Water」「Madecassoside(マデカソサイド)」「Asiaticoside(アジアチコサイド)」といった表記で出てくる。マデカソサイドはシカの中の有効成分を高濃度で抽出したもので、後者ほど鎮静パワーが強いと考えられている。

代表的なブランドは、Anua の Heartleaf シリーズ(ハートリーフ = ドクダミ系だが鎮静ジャンル)、COSRX の Centella Aqua シリーズ、Skin1004 の Madagascar Centella シリーズ、Abib の Heartleaf Spot Pad など。日本でも OliveYoung 日本や @cosme TOKYO で主要ラインが揃う。

向いている人: 季節の変わり目に赤くなりやすい。マスクで肌が荒れがち。ニキビ後の赤みが消えにくい。海外旅行で肌が荒れた直後のリカバリー期。

注意点としては、鎮静系は「効いている実感」が地味なジャンル。即効性で「ツヤが出た」のような分かりやすい変化は出にくく、2〜4週間使い続けて初めて「そういえば赤くなる頻度が減った」と気づくタイプ。途中で「効いていない」と判断して切り替えると本来の効果が見られない。

## 美白・くすみ ― ナイアシンアミド と トラネキサム酸

「シミ」「くすみ」「色ムラ」の悩みに対応するのが美白系。

韓国コスメで2026年現在もっとも主流なのが Niacinamide(ナイアシンアミド)。ビタミン B3 の一種で、メラニン生成の抑制とバリア機能サポートの両方が期待される、いわば「コスパ最強」の美白成分。日本でも医薬部外品の美白有効成分として承認されている。

韓国製品では2%〜10%の濃度幅で配合されることが多く、5%前後が定番。Beauty of Joseon の Glow Serum(Propolis + Niacinamide)、COSRX の The Niacinamide 15 Serum、Anua の Niacinamide Toner 系などが代表格。

もう一つ覚えておきたいのが Tranexamic Acid(トラネキサム酸)。元々は止血剤として開発された医薬品成分で、メラノサイトを刺激するプラスミンの働きを抑える経路で「肝斑」に効くことが分かり、医薬品・医薬部外品・化粧品の3階層で利用されている。日本でも美白有効成分として承認済み。

トラネキサム酸が入った韓国コスメは、SKIN1004 の Hyalu-Cica Brightening、Some By Mi の Snail Truecica、ISNTREE の Tranexamic シリーズなど。シミの種類が「肝斑」(両頬に左右対称に出るもや)の人は、ナイアシンアミドよりトラネキサム酸を試す価値がある。

注意点。美白成分は紫外線対策とセットでなければ効果が出ない。SPF 50+ の日焼け止めを毎日塗らない限り、どれだけ高価な美白美容液を使ってもメラニン生成のほうが追いつかない。日焼け止めの徹底が9割、美白美容液は1割というのが現実的な見方。

## ハリ・エイジング ― ペプチド と ポリヌクレオチド系の入り口

「ハリ不足」「ほうれい線」「目元のたるみ」に対応するのがエイジング系。

このジャンルでまず覚えるべきは Peptide(ペプチド)。アミノ酸が数個つながった短い鎖で、皮膚のコラーゲン産生を促す経路で「ハリ」を出す働きが研究されている。化粧品原料としては Matrixyl(マトリキシル)、Argireline(アルジルリン)、Copper Peptide(銅ペプチド)などのシリーズ名で広く流通している。

韓国コスメでペプチドの旗艦になっているのが、COSRX の The Peptide シリーズ(6 Peptide / The 6 Peptide Skin Booster Serum)、Medi-Peel の Peptide 9 シリーズ、Mary&May の系列。日本でも OliveYoung 日本で主要ラインが揃う。

そしてこのジャンルでいま話題なのが PDRN(ポリデオキシリボヌクレオチド)と エクソソーム の2つ。前者はサーモン由来の DNA 断片、後者は細胞外小胞という別カテゴリだが、どちらも「組織再生」の文脈で皮膚科クリニックの注入療法から化粧品ジャンルへ降りてきた成分。

ただしこの2つは入門向けではない。濃度・由来・組み合わせのリテラシーが必要で、Free 入門記事の枠を超える。別記事で薬理学的な根拠と「化粧品ジャンルでの限界」を踏み込んで書く予定なので、まずは Peptide シリーズで「ハリの成分はこういう感覚で効く」という基準を作ってから進むのを勧める。

注意点。ハリ系の成分は「真皮層に届くかどうか」という議論が常につきまとう。化粧品グレードの分子量で深部まで届くかは諸説あり、即効性を求めると失望しやすい。ベースラインのスキンケア(洗顔・保湿・日焼け止め)を整えた上で、3ヶ月単位の長期戦として組み込むのが現実的。

## 毛穴・角質 ― AHA / BHA / PHA の使い分け

「毛穴の黒ずみ」「ザラつき」「ニキビ予防」の悩みに対応するのが角質ケア系。

韓国コスメで覚えるべきは AHA(アルファヒドロキシ酸)、BHA(ベータヒドロキシ酸)、PHA(ポリヒドロキシ酸)の3兄弟。すべて「古い角質を剥がす」働きの酸だが、性質が違う。

AHA(代表は乳酸・グリコール酸)は水溶性で、肌表面の角質に作用する。くすみ・ザラつきに有効で、即効性が出やすい一方、刺激も比較的強い。Some By Mi の AHA-BHA-PHA 30 Days Miracle ラインや、Cosrx の AHA 系がこのジャンル。

BHA(代表はサリチル酸 = β-ヒドロキシ酸)は油溶性で、毛穴の内側の皮脂と角質に作用する。毛穴の黒ずみ・ニキビ予防に強い。COSRX の BHA Blackhead Power Liquid、Paula's Choice の BHA 系列(韓国コスメではないが定番)など。

PHA(代表はグルコノラクトン)は分子量が大きく、肌表面でゆっくり作用する。AHA より刺激が弱く、敏感肌でも使いやすい。Cosrx の PHA 系、Beauty of Joseon の角質ケア系などに配合される。

選び方の目安。毛穴の黒ずみが目立つなら BHA。くすみとザラつきが主訴なら AHA。敏感肌で AHA がしみるなら PHA。複数同時に使うと過剰剥離になるので、必ず1つだけから始める。

注意点。酸系を使い始めた最初の2週間は紫外線への感受性が上がる。日焼け止めの SPF はこの期間とくに重要。また、レチノールやビタミンCとの併用は刺激が積み上がりやすいので、夜と朝に分ける、隔日にする、などの設計が必要。

## 乾燥・バリア ― ヒアルロン酸 と セラミド

「乾燥」「インナードライ」「バリア低下」の悩みに対応するのが保湿系。

ヒアルロン酸 は化粧品保湿成分の代表格で、もはや「入っていない韓国コスメを探すほうが難しい」レベル。重要なのは「分子量の違うヒアルロン酸が複数入っているか」という観点。高分子は肌表面に膜を作って蒸散を防ぎ、低分子はより深い層まで届いて潤いを保つ。複数分子量のヒアルロン酸を組み合わせた製品は「マルチモレキュラー」「マルチサイズ」と表記されることが多い。

代表は Torriden の Dive-In Low Molecular Hyaluronic Acid Serum、Isntree の Hyaluronic Acid Toner Plus、Anua の Heartleaf Quercetinol Hyalu-Cica など。日本では OliveYoung 日本と @cosme TOKYO の両方で主要ラインが揃う。

そしてヒアルロン酸とセットで覚えるべきが Ceramide(セラミド)。肌のバリア機能を担う細胞間脂質の主成分で、加齢や洗いすぎで減少する。バリアが薄くなると、どれだけ高価な美容液を入れても水分が逃げてしまうので、土台として最重要。

セラミド配合の代表は、Dr.Jart+ の Ceramidin シリーズ、ILLIYOON の Ceramide Ato Lotion、Round Lab の 1025 Dokdo シリーズなど。とくに Dr.Jart+ の Ceramidin はバリア改善の体感が早いと評判で、冬場のごわつきが気になる人に勧められる。

順序の目安。化粧水→ヒアルロン酸美容液→セラミド配合のクリーム、の3層を作ると、保湿は基本完成する。これが整っていない状態で美白やエイジング系を重ねても効果が薄い。

## 注意したい「組み合わせNG」5つ

最後に、複数の有効成分を同時に使うときに知っておくべき禁則をまとめる。

第一に、AHA・BHA × レチノール の同時夜使用。両方とも角質剥離とターンオーバー促進を促すので、同時に使うと肌のキャパを超えて炎症・皮むけになる。レチノールは夜のみ、酸系は朝もしくは隔日、というのが安全策。

第二に、ビタミンC × ナイアシンアミドの同時使用論争。古典的には「ビタミンCの酸性とナイアシンアミドの中性 pH が反応してナイアシンを生成、刺激の原因になる」と言われてきた。最近の研究では純粋なアスコルビン酸ではなく誘導体型なら問題ないとされるが、敏感肌で炎症が起きやすい人は朝ビタミンC・夜ナイアシンアミドの時間差使用が無難。

第三に、レチノール × ビタミンC の同時使用。両者の pH 帯が大きく異なるため、効果が打ち消し合うとされる。朝ビタミンC・夜レチノールの時間差使用が定番。

第四に、ペプチド × 強酸(AHA・BHA 高濃度) の同時使用。酸の pH 環境でペプチドの構造が崩れる可能性があり、ペプチド美容液の効果が下がる。酸系を朝・ペプチドを夜、または日を分ける運用が現実的。

第五に、複数の美白成分の同時投入。ナイアシンアミド・トラネキサム酸・アルブチン・ハイドロキノン誘導体などを一気に重ねるとバリアが追いつかず、敏感化・赤みのリバウンドが起きる。1ジャンル1成分で始めるのが原則。

## パッチテストと「1週間1商品」ルール

成分名を覚えても、自分の肌に合うかは試さないと分からない。

新しい商品を導入するときの基本ルールは2つ。

パッチテスト。耳の後ろか二の腕の内側に少量を塗り、24時間置いて赤み・かゆみが出ないか確認する。化粧水・美容液・クリームのすべてでこれを行うのが理想だが、最低限「有効成分が高濃度のもの」(酸系・レチノール・高濃度ビタミンC)は必ず実施する。

そして「1週間1商品ルール」。新しいスキンケアを導入するときは、1週間に1つだけ加える。同時に2つ3つ加えると、肌トラブルが出たときにどれが原因か特定できなくなる。地味だが事故率を劇的に下げる。

このルールを守るだけで、年間のスキンケア事故は8割減らせる、というのが個人的な体感。

買うときに迷ったら、自分の悩みを1つだけ決めて、上のリストから1成分だけ選ぶ。その成分が入った代表ブランドを姉妹記事の[韓国コスメを日本で買う4つの場所](https://note.com/note-user/n/n4e037aa7aeed)を見ながら入手する。これだけで「効くか効かないか分からない迷子状態」から1段抜けられる。
